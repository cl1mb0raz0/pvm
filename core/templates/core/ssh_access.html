What to Ask the Sysadmins

  1. Create a Dedicated Account, {{ default_user }}, with No Sudo and No Password.
  2. Install This Script as {{ remote_command }} (Owned by Root, Mode 755). It Only Reads the OS Release, the Kernel Version and the Package List:
    {{ script }}
  3. Add the authorized_keys Line Shown Here. Even If the Key Were Stolen, It Could Only Run This Script.
  4. Allow SSH (Port 22 or the Host's Port) from the Pvm VM to the Hosts.

Then, on Each Host's Installed Packages Tab, an Admin Enables SSH and Confirms the Server's Host Key Fingerprint on First Contact.
